# 🔍 CLI Text Search Engine

A stylish, interactive Python command-line utility for searching keywords across local `.txt` files with animated terminal UI effects and dynamic keyword highlighting.

---

## ✨ Features

* **Animated Terminal Interface:** Includes custom ASCII art, typing effects, and formatted console feedback.
* **Directory Browser:** Select any target folder containing `.txt` files.
* **Interactive File Selection:** Easily pick from available text files using simple numbered menu choices.
* **Keyword Search & Highlighting:** Real-time search that scans files line-by-line and highlights matching terms directly in the terminal output.
* **Case-Insensitive Matcher:** Finds keywords regardless of capitalization.
